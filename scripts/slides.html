System Architecture & Key Innovations

Engineered for Absolute Containment

ARGUS removes the attacker's asymmetric advantage by strictly isolating decoy interactions from production infrastructure.

Zero Database Access

The decoy portal contains no database credentials, ORM models, or connection pools. All telemetry is dispatched via an in-memory buffered HTTP ForwardingEventSink, preventing lateral pivoting.

Zero-Plaintext Policy

Attacker-submitted passwords are never logged in plaintext. ARGUS records password length and an HMAC-SHA256 fingerprint to identify coordinated credential-stuffing campaigns safely.

Multi-Vector Decoy Surface
